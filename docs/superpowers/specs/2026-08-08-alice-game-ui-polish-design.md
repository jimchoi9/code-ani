# Alice Game UI Polish

## Scope

- Polish only the `current` and `visual-novel` variants.
- Do not modify the mock illustrations, their SVG files, or illustration selectors.
- Do not modify the `minimal` renderer or stylesheet.

## Direction

Use a bright casual-fantasy game language inspired by the clarity and tactile feedback of polished mobile adventure games. Avoid copying branded shapes or ornaments. Replace heavy outlines with translucent 1px edges, layered soft shadows, warm panels, clear color hierarchy, and short 1-2px press motion.

The current UI becomes a light story-game surface with ivory panels, jewel-colored choice cards, compact vocabulary chips, and softer form controls. The visual-novel UI becomes a cinematic navy dialogue deck with warm gold accents, elevated choice cards, and a more deliberate progress trail. Content, layout behavior, story state, and assets remain unchanged.

## Acceptance

- No thick dark borders on primary panels or controls.
- Controls retain at least 44px touch targets and visible keyboard focus.
- Current and visual-novel screens remain readable on mobile and desktop.
- Minimal UI and mock illustration code remain byte-for-byte unchanged.
