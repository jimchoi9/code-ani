# PNG 캐릭터 파츠 리깅 실험 설계

## 목적

`output/character/`의 투명 PNG 파츠를 레이어로 조립해 관절 애니메이션, 표정 교체, 방향 전환과 간단한 대사 립싱크 가능성을 검증한다. 기존 SVG 프로토타입과 분리된 `png-rig.html` 페이지로 제공한다.

## 자산과 제약

사용 자산은 `output/character/manifest.json`에 등록된 21개 PNG다. 머리, 몸통, 좌우 팔은 독립 애니메이션 레이어로 사용한다. 다리와 발은 좌우가 묶인 이미지이므로 하체 레이어로 사용하고 개별 보행은 범위에서 제외한다.

manifest의 pivot은 crop 중심이며 실제 관절점이 아니다. 프로토타입 전용 리그 설정에서 머리 연결점, 양 어깨와 입 위치를 수동 보정한다. 원본 PNG와 manifest는 수정하지 않는다.

## 화면 구성

페이지는 다음 영역으로 구성한다.

- 중앙 캐릭터 무대와 말풍선
- 동작: 안녕하세요, 고개 끄덕이기, 팔 흔들기, 점프하기
- 표정: 기본, 행복, 놀람, 화남, 슬픔
- 방향: 정면, 왼쪽 3/4, 오른쪽 3/4, 측면
- 관절점 표시 토글
- 실험 목록으로 돌아가는 링크

`index.html`의 보조 기술 실험 그룹에 “PNG 파츠 리깅” 카드를 추가한다.

## 레이어 구조

정면 리그는 고정 배치와 애니메이션 transform이 충돌하지 않도록 각 파츠를 배치 래퍼와 모션 래퍼로 분리한다. 뒤에서 앞으로 하체, 몸통, 팔, 머리, 입 순서로 쌓는다.

표정 버튼은 머리 전체 PNG를 교체한다. 말하기 동작에서는 기본 머리 위의 입 영역을 피부색 패치로 가리고 입 PNG를 교체한다. 대사 종료 후 입 패치와 입 레이어를 숨기고 현재 선택된 표정 머리를 다시 표시한다.

방향 전환은 완성 포즈 이미지 네 장을 사용한다. 정면 이외 방향에서는 개별 리그를 숨기고 완성 포즈를 보여준다. 리깅 동작 버튼을 누르면 정면 모드로 복귀한 뒤 동작을 재생한다.

## 동작

- 고개 끄덕이기: 목 연결점을 기준으로 짧게 앞뒤 회전한다.
- 팔 흔들기: 오른쪽 어깨를 기준으로 팔을 세 차례 흔든다.
- 점프하기: 캐릭터 리그 전체가 위로 이동하고 착지한다.
- 안녕하세요: 말풍선을 표시하고 오른팔 흔들기, 머리 끄덕임과 `closed → a → o → u → smile → closed` 입 교체를 함께 재생한다.

동작 중 같은 버튼이나 다른 동작을 누르면 기존 타임라인과 타이머를 정리하고 기본 transform에서 새 동작을 시작한다. 페이지가 숨겨지면 동작을 중단하고 자동 재개하지 않는다.

## 접근성 및 모션

모든 컨트롤은 실제 HTML 버튼으로 제공하며 키보드로 사용할 수 있다. 현재 표정과 방향은 `aria-pressed`로 표시하고 상태 변화는 polite live region으로 전달한다.

`prefers-reduced-motion: reduce`에서는 큰 이동과 반복 회전을 생략하고 짧은 투명도·크기 강조로 대체한다. 표정, 방향, 말풍선과 입 모양 순환은 유지한다.

## 오류 처리

페이지 시작 시 manifest와 필수 이미지 로딩을 확인한다. 누락된 개별 자산은 해당 버튼만 비활성화하고 상태 영역에 원인을 표시한다. 동작 도중 발생한 이미지 로딩 실패가 다른 컨트롤을 막지 않게 한다.

## 테스트

정적/브라우저 테스트는 다음을 확인한다.

- index에 PNG 리깅 실험 카드가 있다.
- manifest의 필수 파츠를 페이지가 참조한다.
- 동작, 표정, 방향, 관절 토글 버튼이 접근 가능한 이름을 가진다.
- 표정과 방향 선택이 이미지와 `aria-pressed`를 갱신한다.
- 안녕하세요 동작이 말풍선을 표시하고 입 순환을 시작한다.
- 반복 실행에서 활성 동작이 하나만 유지된다.
- reduced-motion에서도 대사와 입 모양 변화가 유지된다.
- 문서 숨김에서 진행 중 동작이 정지한다.
- 390px 모바일 viewport에서 무대와 컨트롤을 사용할 수 있다.
- 기존 프로토타입에 JavaScript 회귀 오류가 없다.

## 성공 기준

- 기본 정면 자세에서 파츠 연결부가 눈에 띄게 벌어지지 않는다.
- 머리와 팔이 각각 지정한 관절점을 중심으로 움직인다.
- 표정 5종과 방향 4종을 즉시 비교할 수 있다.
- “안녕하세요!” 동작에서 팔·머리·입과 말풍선이 함께 반응한다.
- 빠른 반복 입력에도 transform과 타이머가 누적되지 않는다.
- 기존 PNG와 manifest를 변경하지 않는다.
