# 캐릭터·사물 인터랙션 놀이터 설계

## 목적

기존 SVG+GSAP 프로토타입에 독립된 인터랙션 놀이터를 추가한다. 사용자는 한 장면에 배치된 주인공과 사물을 마우스, 터치 또는 키보드로 선택하고, 대상별 시각 애니메이션과 짧은 말풍선 반응을 반복해서 확인할 수 있다.

이번 프로토타입은 오디오, 미션 진행, 점수 또는 이야기 분기를 다루지 않는다. 클릭 가능한 SVG 대상의 구조, 반응 재생 방식, 모바일 터치 영역, 키보드 접근성 및 reduced-motion 대응을 검증하는 데 집중한다.

## 사용자 경험

`interaction.html`은 방 또는 마당을 배경으로 한 단일 화면 놀이터다. 첫 진입 시 “친구들과 물건을 눌러 보세요!”라는 짧은 안내를 보여준다.

다음 다섯 대상을 선택할 수 있다.

- 나비: 통통 뛰며 “나랑 놀자!”
- 몽이: 꼬리를 흔들며 “멍멍! 반가워!”
- 공: 튀어 오르며 “통통!”
- 꽃: 좌우로 흔들리며 “간질간질~”
- 구름: 옆으로 살짝 떠가며 “둥실둥실”

대상을 선택하면 대상 가까이에 말풍선이 나타나고 해당 애니메이션이 처음부터 재생된다. 같은 대상을 반응 도중 다시 선택해도 현재 재생을 이어가지 않고 처음부터 다시 시작한다. 다른 대상을 선택하면 이전 말풍선은 닫히고 새 대상의 반응을 재생한다. 서로 다른 대상의 장식 애니메이션이 무한히 누적되지 않게 한다.

## 페이지 구성

새 파일 `interaction.html`을 만들고 `index.html`의 “보조 기술 실험” 그룹에 “인터랙션 놀이터” 카드를 추가한다.

페이지는 다음 영역으로 구성한다.

1. 상단 제목과 한 줄 안내
2. 반응 대상을 포함하는 반응형 SVG 무대
3. 현재 반응 문구를 보조적으로 전달하는 접근성 live region
4. index로 돌아가는 링크

무대는 기존 페이지와 동일한 손그림 톤과 색상 체계를 사용한다. 캐릭터는 `characters.js`의 `def-nabi`, `def-mongi`를 재사용한다. 공은 기존 `def-ball`을 재사용하고, 꽃과 구름은 이 페이지에 필요한 단순 SVG 그룹으로 작성한다.

## 인터랙션 구조

선택 가능한 각 SVG 그룹은 다음 공통 계약을 따른다.

- 안정적인 `data-interaction` 식별자
- `role="button"`
- `tabindex="0"`
- 대상을 설명하는 `aria-label`
- 시각적 포커스 및 hover 표시
- 실제 그림보다 약간 넓은 투명 hit area

JavaScript에는 식별자를 반응 정의에 연결하는 작은 레지스트리를 둔다. 각 정의는 대상 노드, 말풍선 문구, GSAP 타임라인 생성 함수로 구성한다. 공통 이벤트 위임은 pointer 또는 click과 `Enter`, `Space` 입력을 동일한 `activateInteraction(id)` 경로로 전달한다.

`activateInteraction`은 다음 순서로 동작한다.

1. 유효한 대상인지 확인한다.
2. 이전에 활성화된 타임라인과 말풍선을 정리한다.
3. 선택 대상의 타임라인을 시작 상태로 되돌린 뒤 재생한다.
4. 대상 가까이에 말풍선을 표시한다.
5. live region에 같은 문구를 반영한다.
6. 반응 종료 후 시각 말풍선을 자연스럽게 숨긴다.

애니메이션 도중 반복 입력이 들어와도 활성 타임라인은 한 개만 유지한다. 페이지가 숨겨지면 진행 중 애니메이션을 정지하고, 다시 보일 때 자동으로 이어 재생하지 않는다.

## 반응형 배치와 입력

SVG는 `viewBox` 기반으로 데스크톱과 모바일 너비에 맞춰 축소한다. 클릭 좌표를 HTML 오버레이로 별도 관리하지 않고, 각 SVG 대상 그룹 내부의 hit area가 그림과 함께 확대·축소되게 한다.

마우스 hover와 키보드 focus에서는 점선 또는 밝은 외곽선으로 선택 가능 상태를 표시한다. 터치 환경에서는 hover에 의존하지 않고 첫 탭에서 즉시 반응한다. 키보드 사용자는 Tab으로 다섯 대상을 순회하고 Enter 또는 Space로 동일한 반응을 실행할 수 있다.

## 모션 접근성

`prefers-reduced-motion: reduce`에서는 큰 이동, 점프, 회전 및 반복 흔들림을 사용하지 않는다. 대신 짧은 색상 강조, 약한 확대 또는 투명도 변화를 한 번 적용하고 말풍선은 동일하게 표시한다.

말풍선 문구는 장식적인 시각 요소와 별도로 polite live region에 전달한다. SVG 대상의 포커스 순서와 이름은 시각 배치 순서와 일치시킨다. 색상 변화만으로 활성 상태를 전달하지 않고 외곽선과 크기 변화도 함께 사용한다.

## 오류 및 의존성 처리

페이지는 기존 프로토타입과 같은 GSAP CDN 의존성을 사용한다. `characters.js`가 먼저 공용 defs를 삽입하고 이후 놀이터 스크립트가 캐릭터 인스턴스를 만든다.

대상 노드가 누락된 경우 해당 반응만 등록하지 않고 콘솔에 식별 가능한 경고를 남긴다. 다른 대상의 상호작용은 계속 동작해야 한다. 빠른 반복 입력이나 다른 대상 전환으로 타임라인이 중복 생성되지 않도록 기존 타임라인을 재사용하거나 명시적으로 종료한다.

이번 범위에서는 CDN 자체 호스팅, 오프라인 폴백, 음원 로딩, 진동 피드백을 추가하지 않는다.

## 테스트

Node 정적 테스트는 다음을 확인한다.

- `interaction.html`이 `characters.js`와 GSAP을 로드한다.
- 다섯 개의 `data-interaction` 대상이 존재한다.
- 모든 대상에 `role`, `tabindex`, `aria-label`이 있다.
- `index.html` 보조 기술 실험에 `interaction.html` 링크가 있다.
- reduced-motion 분기와 visibility 수명주기 처리가 존재한다.

브라우저 테스트는 다음을 확인한다.

- 페이지가 JavaScript 오류 없이 초기화된다.
- 각 대상을 클릭하면 알맞은 말풍선과 활성 상태가 나타난다.
- 같은 대상을 다시 클릭하면 반응 재생 상태가 처음부터 시작된다.
- 다른 대상을 클릭하면 이전 말풍선이 새 문구로 교체된다.
- Enter와 Space 입력이 클릭과 같은 결과를 만든다.
- reduced-motion 환경에서도 말풍선과 상태 피드백은 유지되며 큰 이동 애니메이션은 사용하지 않는다.
- 좁은 모바일 viewport에서도 다섯 대상이 무대 안에 있고 터치할 수 있다.

## 성공 기준

- 사용자가 별도 설명 없이 다섯 대상을 찾아 눌러볼 수 있다.
- 마우스, 터치, 키보드 입력이 동일한 반응 경로를 사용한다.
- 반응 중 반복 입력과 대상 전환에도 애니메이션이 누적되거나 멈춘 상태로 남지 않는다.
- 기존 캐릭터와 공 자산을 복제하지 않고 공유 defs에서 재사용한다.
- reduced-motion 환경에서도 정보와 재미 요소인 말풍선을 잃지 않는다.
- 기존 스크롤판, 재생판 및 다른 보조 실험의 동작에는 변화가 없다.
