# 앨리스 테스트 처음으로 버튼 설계

## 목적

테스트 진행 중 어느 화면에서든 헤더의 `← 처음으로` 버튼을 눌러 최초 참가자 코드 입력 화면으로 돌아갈 수 있게 한다.

## 화면과 동작

- 공통 테스트 내비게이션에 `← 처음으로` 버튼을 추가한다.
- 버튼은 참가자 입력, 시계토끼 온보딩, 이야기 장면, 결말, 테스트 완료 화면을 포함한 모든 메인 화면에서 같은 위치와 동작을 유지한다.
- 클릭 시 확인창 없이 즉시 최초 참가자 코드 입력 화면으로 이동한다.
- 현재 참가자 테스트 기록, 이야기 세션, 온보딩 답변, 미니멀 UI 문장 진행 위치를 모두 삭제한다.
- 설정 페이지에서 선택한 UI 값은 삭제하지 않는다. 돌아온 참가자 입력 화면과 다음 테스트에서도 선택한 UI를 유지한다.

## 구현 경계

- 공통 내비게이션 렌더러가 버튼 마크업을 제공한다.
- 앱의 위임 클릭 처리에 전용 `return-to-start` 동작을 추가한다.
- 실제 초기화는 기존 저장소 경계인 session store, minimal store, test store를 통해 수행한다.
- 각 UI 렌더러에는 별도 초기화 로직을 추가하지 않는다.

## 접근성 및 스타일

- 버튼의 보이는 이름은 `← 처음으로`로 한다.
- 기존 `UI 설정` 링크와 함께 `테스트 설정` 내비게이션 안에 배치한다.
- 모바일에서도 최소 44px 상호작용 영역을 유지한다.

## 검증

- 공통 내비게이션에 `return-to-start` 버튼과 `UI 설정` 링크가 함께 렌더링되는지 테스트한다.
- 이야기 진행 중 버튼을 누르면 세 저장소가 초기화되고 setup 화면으로 전환되는지 통합 테스트한다.
- 선택한 UI preference store는 초기화하지 않는지 통합 테스트한다.
- 전체 자동 테스트와 실제 브라우저에서 `설정 → 테스트 시작 → 이야기 진행 → 처음으로 → 참가자 코드 입력` 흐름을 확인한다.
