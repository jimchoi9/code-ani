# SVG 애니메이션 프로토타입 비교 기반 개선 설계

## 목적

현재 저장소는 완성 제품을 만드는 단계가 아니라 SVG+GSAP, Lottie, 서로 다른 SVG 스타일과 외부 캐릭터 교체 가능성을 비교하는 기술 검증 단계다. 이번 작업은 개별 프로토타입의 완성도를 높이기보다 비교 조건을 일관되게 만들고, 불필요한 런타임 비용을 제거하며, 향후 캐릭터 아트가 애니메이션 파이프라인에 들어올 수 있는 최소 계약을 명시한다.

## 범위

이번 작업에 포함한다.

- `characters.js`를 현재 이야기용 SVG 캐릭터·소품·배경 defs의 단일 원본으로 사용한다.
- `webtoon.html`의 인라인 공용 defs와 배경을 제거하고 `characters.js`를 로드한다.
- `webtoon.html`의 화면 밖 무한 반복 트윈을 정지하고 다시 진입하면 재개한다.
- SVG boil 주기를 200ms로 통일하고, 문서가 숨겨진 동안 중단한다.
- 장식용 무한 모션과 boil에 `prefers-reduced-motion` 대응을 추가한다.
- `player.html` 자막 변경을 스크린리더가 인식할 수 있게 한다.
- 외부/AI 생성 아트를 위한 파츠 분리 SVG 제작 계약을 문서화한다.
- `index.html`에서 현재 비교 대상, 보조 실험, 초기 아카이브의 역할을 구분한다.

이번 작업에서 제외한다.

- Lottie 5개 씬 전체 제작
- `nabi_scene1.json`을 동등 복잡도 리그로 확장하는 작업
- CDN 자체 호스팅, SRI, 네트워크 폴백
- 실기기 FPS 수치 측정 자동화
- `kid-style.html`의 독자적인 디자인을 `characters.js`와 동일한 리그로 교체
- 프로토타입 파일 삭제

## defs 구조

`characters.js`는 현재 이야기에서 공유하는 다음 자산의 유일한 원본이다.

- 필터와 패턴: `wob1`, `wob2`, `wobBg`, `crayon`
- 캐릭터: `def-nabi`, `def-mongi`, `def-owl`
- 소품: `def-ball`, `def-half-l`, `def-half-r`, `def-star`
- 배경: `def-room`, `def-yard`, `def-dusk`

`webtoon.html`은 `<body>` 시작 직후 `characters.js`를 동기적으로 로드한다. 씬 SVG가 파싱되기 전에 공용 defs가 문서에 삽입되므로 기존 `url(#...)` 참조와 배경 복제 코드가 그대로 동작한다. 웹툰에 인라인으로 있던 공용 defs 및 복제 대상 배경 마크업은 삭제한다.

`player.html`과 `swap-test.html`은 기존 공용 로딩 방식을 유지한다. `kid-style.html`은 현재 독립적인 스타일 비교판이므로 공용 리그로 바꾸지 않는다. 대신 타이머 수명주기와 reduced-motion 정책만 맞춘다. 초기 기술 시안인 `svg-gsap.html`도 defs 통합 대상에서 제외하고 아카이브로 표시한다.

## 애니메이션 수명주기

### 웹툰 씬

각 씬은 자신이 만든 `repeat: -1` GSAP 트윈을 `loops` 배열로 소유한다. `sceneTL()`이 만드는 ScrollTrigger는 다음 정책을 적용한다.

- 씬 진입: 해당 씬의 루프를 재개한다.
- 씬 이탈: 해당 씬의 루프를 일시 정지한다.
- 생성 직후: 화면에 없는 씬의 루프는 정지 상태다.
- 스크롤 타임라인 자체는 ScrollTrigger가 계속 관리하므로 스크럽 위치와 되감기는 유지한다.

표지 무한 트윈은 별도 수명주기 대상으로 관리하고 표지가 뷰포트와 교차할 때만 실행한다. 이를 위해 IntersectionObserver를 사용하되, 지원되지 않는 환경에서는 기존처럼 실행하는 안전한 폴백을 둔다.

씬 섹션에는 `content-visibility: auto`와 합리적인 `contain-intrinsic-size`를 적용한다. ScrollTrigger pin 레이아웃과 충돌하는 경우 테스트에서 제외하거나 되돌릴 수 있도록 CSS 변경을 분리한다.

### boil 타이머

boil seed 변경 간격은 130ms에서 200ms로 늘린다. 다음 조건을 모두 만족할 때만 타이머를 실행한다.

- 문서가 보이는 상태다.
- 사용자가 reduced motion을 요청하지 않았다.
- 해당 페이지에서 boil 효과가 활성 상태다.

`visibilitychange`와 `prefers-reduced-motion` 미디어 쿼리 변경을 구독해 실행 상태를 갱신한다. `swap-test.html`의 사용자가 직접 끄는 손그림 필터 토글은 기존 동작을 유지한다.

## reduced motion

`prefers-reduced-motion: reduce`에서는 이야기와 자막을 제거하지 않고 장식적 움직임만 최소화한다.

- boil seed 교체를 실행하지 않는다.
- `repeat: -1` 트윈을 실행하지 않는다.
- 스크롤판의 핵심 장면 타임라인은 스크롤 위치에 따라 최종 상태를 보여줄 수 있도록 유지한다.
- CSS의 부드러운 스크롤은 `auto`로 낮춘다.
- 자막 표시와 콘텐츠 탐색은 유지한다.

이 정책은 “모든 연출 제거”가 아니라 멀미를 유발하기 쉬운 지속 흔들림과 필터 변화 제거를 목표로 한다.

## 접근성

`player.html`의 `#caption`에는 `aria-live="polite"`와 `aria-atomic="true"`를 추가한다. 자동재생 중 문장이 바뀔 때 현재 문장 전체를 무리하게 끼어들지 않고 안내한다. 빈 문자열로 자막을 내리는 기존 동작은 유지한다.

## 아트 제작 계약

새 문서 `ART-SPEC.md`에 다음을 요구한다.

- 캐릭터는 머리, 몸통, 좌우 귀, 꼬리, 눈, 입, 장신구를 의미 있는 그룹으로 분리한다.
- 애니메이션 대상 그룹은 안정적인 `data-p` 이름을 가진다.
- 표정은 `data-face` 그룹으로 구분한다.
- 캐릭터 로컬 원점은 발밑 중앙 `(0,0)`이다.
- 머리와 몸통처럼 서로 다른 관절을 하나의 외곽선 path로 묶지 않는다.
- 회전 파츠는 연결부 아래에 충분한 겹침 영역을 둬 회전 시 틈이 보이지 않게 한다.
- 마스크, clipPath, 필터, 임베디드 래스터 이미지 사용 여부를 납품 시 명시한다.
- 텍스트는 경로로 변환하거나 프로젝트가 보장하는 폰트만 사용한다.
- `new_char.svg`는 통짜 외곽선과 꼬리 누락 때문에 부분 리깅이 불가능한 실패 사례로 기록한다.

이번 작업은 자동 검사기를 만들지 않고, 사람이 납품 전에 확인할 체크리스트까지만 제공한다.

## index 분류

`index.html`은 링크를 삭제하지 않고 다음 세 그룹으로 구분한다.

1. 현재 비교 대상: `webtoon.html`, `player.html`
2. 보조 실험: `lottie.html`, `kid-style.html`, `swap-test.html`
3. 초기 아카이브: `svg-gsap.html`

각 카드에는 무엇을 검증하는 파일인지와 현재 비교 한계를 짧게 표시한다. Lottie 카드는 단일 씬·저복잡도 기준임을 명시하고, `swap-test.html`은 파츠 분리 요구를 검증하는 실험으로 노출한다.

## 검증

자동 검증은 외부 테스트 프레임워크를 새로 도입하지 않고 Node 기반 정적 회귀 테스트를 추가한다. 테스트는 최소한 다음을 확인한다.

- `webtoon.html`에 `def-nabi`, `def-mongi`, `def-room` 정의가 없고 `characters.js`를 로드한다.
- 공용 defs ID가 `characters.js`에 존재한다.
- 웹툰의 각 씬 무한 트윈이 씬별 loops에 등록되고 진입/이탈 콜백으로 제어된다.
- boil 간격이 대상 페이지에서 200ms이며 숨김 문서와 reduced motion에서 정지한다.
- `player.html` 자막에 live-region 속성이 있다.
- index에 비교 대상, 보조 실험, 아카이브 구분과 캐릭터 교체 실험 링크가 있다.
- `ART-SPEC.md`에 필수 파츠, 원점, path 분리 규칙이 있다.

브라우저 검증에서는 다음을 확인한다.

- 스크롤판과 재생판의 캐릭터·배경이 동일하게 렌더링된다.
- 웹툰을 위아래로 되감아도 씬 스크럽 상태가 유지된다.
- 현재 보이는 씬만 장식 루프가 움직인다.
- reduced motion 에뮬레이션 시 지속 흔들림은 없지만 자막과 스크롤 진행은 유지된다.
- `player.html`의 자동재생·이전·다음·일시정지가 기존처럼 동작한다.
- 브라우저 콘솔에 누락된 defs, GSAP target, 중복 ID 오류가 없다.

## 성공 기준

- 스크롤판과 재생판의 이야기 자산을 변경할 때 `characters.js` 한 곳만 수정하면 된다.
- 웹툰에서 화면 밖 씬의 무한 트윈이 실행되지 않는다.
- 모든 활성 SVG 프로토타입의 boil이 백그라운드와 reduced-motion 환경에서 중단된다.
- 기술 비교 페이지가 각 파일의 목적과 한계를 오해 없이 보여준다.
- 외부 캐릭터 아트가 리깅 가능하려면 어떤 구조로 납품되어야 하는지 문서만으로 판단할 수 있다.
