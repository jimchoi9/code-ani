# 패럴랙스 놀이터 설계

## 목표

기존 SVG 캐릭터와 손그림풍을 재사용해, 배경·중경·전경이 서로 다른 속도로 움직이는 패럴랙스 기술을 한 페이지에서 확인한다. 사용자는 스크롤과 포인터 이동으로 깊이감을 직접 체험하고, 비교 버튼으로 효과를 즉시 켜고 끌 수 있다.

## 접근 방식

검토한 선택지는 세 가지다.

1. CSS `background-attachment: fixed`: 구현은 가장 작지만 레이어별 제어와 모바일 일관성이 부족하다.
2. GSAP ScrollTrigger: 타임라인 제작에는 강하지만 이 실험의 핵심인 깊이 계산을 확인하기 위해 외부 런타임을 추가할 필요가 없다.
3. CSS transform + 작은 JavaScript 컨트롤러: 스크롤과 포인터 값을 같은 계산식에 넣을 수 있고, 레이어별 깊이를 명시적으로 비교할 수 있다.

3번을 채택한다. 의존성이 없고, 현재 프로토타입의 정적 HTML 구조와 테스트 방식에 가장 잘 맞는다.

## 화면과 동작

- `parallax.html`은 높이가 긴 스크롤 구간과 화면에 고정되는 하나의 무대를 가진다.
- 무대는 하늘, 해, 먼 산, 구름, 언덕, 나비·몽이, 앞쪽 풀잎의 7개 이상 레이어로 구성한다.
- 각 레이어는 `data-depth`와 `data-scroll` 값을 가진다. 전경일수록 포인터와 스크롤에 더 크게 반응한다.
- 스크롤 진행도는 화면의 세로 진행 표시와 접근 가능한 `progressbar` 값에 반영한다.
- 포인터가 무대 안에서 이동하면 레이어가 깊이에 비례해 미세하게 이동한다. 포인터가 무대를 벗어나면 중심으로 부드럽게 돌아온다.
- “패럴랙스 켜짐/꺼짐” 버튼으로 효과를 비교한다. 꺼진 상태에서는 모든 레이어가 원위치로 돌아간다.
- `prefers-reduced-motion: reduce`에서는 레이어 transform과 보간 루프를 사용하지 않고 정적인 장면을 제공한다.
- 문서가 숨겨지면 애니메이션 프레임을 중단하고, 다시 보이면 필요한 경우 재개한다.

## 구조

- `parallax.html`: 무대 마크업, SVG 레이어, 반응형 스타일, 접근성 텍스트.
- `parallax.js`: 스크롤/포인터 입력 수집, 깊이 계산, transform 적용, 생명주기 관리.
- `tests/parallax-static.test.cjs`: 페이지 구조, 깊이 메타데이터, 메인 진입 카드 검증.
- `tests/parallax-browser.test.cjs`: 실제 스크롤/포인터 반응, 토글, 모션 감소, 모바일 경계 검증.

## 성공 기준

- 먼 레이어보다 가까운 레이어의 이동량이 크다.
- 스크롤과 포인터 입력이 동시에 적용되어도 한 개의 프레임 루프만 사용한다.
- 효과를 끄거나 모션 감소 설정을 사용하면 레이어가 움직이지 않는다.
- 390px 모바일 화면에서 가로 스크롤이 발생하지 않는다.
- 기존 프로토타입 전체 회귀 테스트에 오류가 추가되지 않는다.
