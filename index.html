현재 기준안 · 5개 씬

평화로운 우리 집 → 갑작스러운 만남 → 장난감 쟁탈전 → 부엉 할아버지의 이야기 → 함께 만드는 새 장난감. 스크롤을 내리면 이야기가 움직입니다.

현재 비교 대상 — 같은 SVG 리그, 다른 재생 방식

스크롤판

세로 스크롤

스크롤 위치가 그대로 재생 위치가 됩니다. 웹툰처럼 내 속도로 읽어 내려가고, 되감기도 자유롭습니다.

재생판

자동재생 · 클릭

그림책을 넘기듯 봅니다. 자동으로 흘러가고, 화면을 누르면 다음 장면으로. 스페이스바로 멈추고 ←→로 오갑니다.

보조 기술 실험

패럴랙스 산책

스크롤 · 포인터 · 깊이

하늘부터 앞쪽 풀잎까지 7단계 레이어를 서로 다른 거리로 움직여 평면 장면의 공간감과 시점 반응을 테스트합니다.

PNG 파츠 리깅

관절 · 표정 · 립싱크

투명 PNG 파츠를 조립해 머리와 팔 관절, 표정·방향 전환, “안녕하세요!” 입 모양 순환을 테스트합니다.

인터랙션 놀이터

클릭 · 터치 · 키보드

나비와 몽이, 공과 꽃, 구름을 직접 눌러 대상별 SVG 반응과 짧은 말풍선을 테스트합니다.

Lottie 기준선

Lottie JSON (lottie-web)

단일 씬·5개 레이어의 저복잡도 프로토타입. 순수 JSON 손작성과 스크롤 프레임 매핑 가능성만 확인하며, 현재 SVG 캐릭터 리그와 동등한 품질 비교는 아닙니다.

스타일 교체 실험

어린이 그림풍 (SVG + GSAP)

같은 SVG+GSAP 기술에서 그림 스타일만 바꾸는 독립 시안. 손그림 필터와 초당 5회 boil 효과의 표현과 비용을 비교합니다.

캐릭터 교체 실험

외부 SVG · 파츠 리깅

자동 트레이싱 SVG를 기존 장면에 넣어 전신 이동과 파츠 애니메이션의 차이를 확인합니다. 파츠 분리 납품 스펙이 왜 필요한지 보여주는 테스트입니다.
