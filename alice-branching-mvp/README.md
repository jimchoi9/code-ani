# 너의 선택으로 열리는 앨리스의 이상한 나라

첨부 마스터 원고를 바탕으로 만든 초등학생 대상 선택형 브라우저 이야기입니다. 이름·나이·좋아하는 간식·함께 갈 친구를 정한 뒤, 선택과 낱말 풀이를 직접 눌러 진행합니다.

전체 이야기는 17개 노드로 구성됩니다. 작아지는 길과 커지는 길에서 각각 세 만남 중 하나를 고르고, 모든 길은 안개 언덕과 붉은 정원으로 모입니다. 만난 친구에 따라 여섯 결말 중 하나에 도달하며, 정원에서 고른 `TRUTH`, `SHIELD`, `TURN`에 따라 각 결말이 세 가지로 달라집니다.

## 실행

`npm test`로 자동 테스트를 실행하고 `npm run serve`로 로컬 서버를 시작합니다.

## 스토리 원고 수정

온보딩에 나이를 직접 입력하면 9살 이하는 `easy`, 10살 이상은 `hard` 원고로 시작합니다. 1 이상의 정수만 허용하며, 레벨이 없는 기존 저장 데이터는 `hard`로 열립니다. 일반적인 제목, 본문, 선택지, 대사, 조건부 문장, 낱말과 뜻풀이는 다음 파일에서 수정합니다.

- `story/content/easy.json`: 쉬운 문장과 쉬운 낱말로 쓴 전체 원고
- `story/content/hard.json`: 화면에 표시되는 전체 원고와 낱말
- `story/graph.json`: 장면 연결, 선택 효과, 조건부 원고 선택 규칙과 삽화 키

문장만 바꿀 때는 대상 난이도의 JSON만 수정합니다. 장면을 추가하거나 분기 결과를 바꿀 때만 `graph.json`과 두 난이도 원고를 함께 수정합니다. `src/generated/story-bundle.js`는 생성 파일이므로 직접 수정하지 않습니다.

원고를 수정한 뒤 다음 명령을 실행합니다.

```bash
npm run story:build
npm test
```

`story:build`는 JSON Schema와 장면 연결, 조건부 블록, 개인화 토큰, 낱말, 삽화 키를 검증한 뒤 정적 앱에서 사용하는 동기식 번들을 생성합니다. `npm test`에 포함된 `story:check`는 JSON과 생성 번들이 다르면 실패합니다.

### 조건부 원고

C1의 고양이 첫 만남과 재회처럼 경로에 따라 달라지는 문장은 각 난이도 JSON의 장면 `blocks`에 있습니다. 본문 배열은 `{ "block": "catMeeting" }`처럼 블록을 참조하고, `graph.json`의 `contentSelectors`가 현재 이야기 상태에 맞는 변형을 고릅니다. 실제 문장은 JavaScript가 아니라 `easy.json` 또는 `hard.json`에서 수정합니다.

### 난이도 구조

`easy.json`과 `hard.json`은 동일한 장면 ID, 선택 ID, 칩 ID와 조건부 블록 키를 사용합니다. 제목, 본문, 선택지 문구, 낱말과 뜻풀이는 난이도별로 다릅니다. 생성 번들에는 두 원고가 모두 포함되며, 온보딩에서 입력한 나이가 이야기 세션의 레벨을 결정합니다.

## 접속 주소

- 테스트 시작: `http://127.0.0.1:8082/`
- UI 설정: `http://127.0.0.1:8082/settings.html`

설정 페이지에서 현재형, 비주얼노벨, 미니멀 텍스트 중 하나를 저장한 뒤 테스트를 시작합니다. 처음 접속했거나 저장된 설정이 없으면 비주얼노벨 UI를 사용합니다. 메인 주소는 선택한 UI와 관계없이 동일합니다.

## 삽화 플레이스홀더

현재 모든 삽화 영역은 회색 화면이며 중앙에 이미지 키만 표시합니다. 세 UI가 모두 같은 키를 사용합니다.

- 시작과 크기 변화: `start_rabbit_hole`, `door_shrink`, `cake_grow`
- 작아진 길의 만남: `door_cat_meet`, `door_caterpillar_meet`, `door_hatter_meet`
- 커진 길의 만남: `cake_cat_meet`, `cake_caterpillar_meet`, `cake_hatter_meet`
- 공통 수렴부: `mist_hill_grin`, `queen_garden_trial_small`, `queen_garden_trial_big`
- 결말: `end_curiosity`, `end_prudence`, `end_cheer`, `end_composure`, `end_selftrust`, `end_warmth`

`queen_garden_trial_small`과 `queen_garden_trial_big`은 각각 작아진 경로와 커진 경로에서 사용합니다. 실제 삽화가 준비되면 이 키를 파일 매핑 기준으로 사용하면 됩니다.

### 판단 기준

- 첫 화면에서 이야기와 선택 중 어디에 먼저 시선이 가는가
- 선택지가 자연스럽게 발견되는가
- 선택 결과가 가장 분명하게 느껴지는가
- 긴 글이 답답하거나 문장이 지나치게 잘게 끊기지 않는가
- 모바일 한 손 진행이 편한가

## 아이와 볼 때 관찰할 것

- 첫 선택 뒤 화면이 달라졌다고 말하거나 반응하는가
- 고른 칩이 결말에 다시 나온 것을 알아차리는가
- 안개 언덕과 붉은 정원에서도 자기 선택이 이어진다고 느끼는가
- 끝까지 스스로 진행하는가
- 다른 결말을 보려고 다시 하기를 누르는가
- 낱말 뜻을 자발적으로 열어 보는가

로컬 기록은 개발자 도구에서 `window.__aliceStoryDebug.session()`으로 확인한다. 이 값은 사용성 참고 자료이며 성향 진단으로 해석하지 않는다.
